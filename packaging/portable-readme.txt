FrameXT 免安装便携版
====================

使用方法
--------
解压到任意目录后，双击 framext.exe 即可运行，无需安装、
无需管理员权限。

便携特性
--------
- 所有数据（界面设置、品牌别名库、自定义模板）保存在本目录
  的 Data 文件夹内，不写入注册表，也不占用系统的 %APPDATA%；
- 整个文件夹可直接复制到 U 盘或其他电脑使用，设置随行；
- 卸载：直接删除整个文件夹即可，不留任何残留。

系统要求
--------
Windows 10 / 11（64 位）。

开源许可
--------
本软件基于 GPLv3+ 开源发布，随包字体的许可全文见 licenses
文件夹。项目主页：https://framext.com
