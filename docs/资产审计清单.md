## 三、界面字体许可核查结论与执行

**对象**：阿里巴巴普惠体 3.0 55 Regular（M4 期用户指定随包嵌入）。

核查过程与证据：

1. TTF name 表内嵌声明：`Copyright (c) 2020-2023 Alibaba (China) Co., Ltd.
   All rights reserved.`，无许可描述（nameID 13）/许可 URL（nameID 14）字段。
2. 官方渠道仅有简短声明「允许任何个人和企业免费使用，包括商用用途，
   但禁止用于违法用途」；官方字体站为 JS 渲染页，未能获取具面协议
  （ICOPIA/EULA）全文，嵌入应用与再分发字体文件的授权范围无法核实。
3. 结论：免费商用 ≠ 明确允许随第三方软件再分发字体文件。按 03-开发计划
   5.5 预设分支「不可分发者换 OFL 等价款」执行。

**执行**：换为思源黑体（Source Han Sans SC）Regular，视觉等价款
（同为现代无衬线，Regular 字重对应）。

- 文件：`resources/fonts/SourceHanSansSC-Regular.otf`（16.5MB，OTF/CFF）
- 许可：SIL Open Font License 1.1，明确允许随软件再分发与嵌入；
  唯二义务 = 随附许可文本、不得将字体单独出售。许可全文随包：
  `licenses/SOURCE-HAN-SANS-LICENSE.txt`
- 来源：https://github.com/adobe-fonts/source-han-sans（release 分支）
- 接线：main.cpp（QFontDatabase 动态取 family）+ theme-light.qss
  font-family（"Source Han Sans SC", "Microsoft YaHei UI" 回退）
- 原普惠体文件已从源码树移除（git 历史可回溯）。

## 三之二、边框文字默认字体 Aileron 落地（2026-10-13）

**对象**：Aileron 0.102 Regular + Bold（原版工具边框文字默认字体，
2026-10 用户指令：默认样式对齐原版附件图 + 默认字体换 Aileron）。

许可核查（双重证据）：

1. 仓库 LICENSE（font-archive/Aileron，字体来源 dotcolon.net 作者官方
   发布镜像）：**CC0 1.0 Universal**（公有领域贡献）。
2. TTF name 表内嵌声明：nameID 0 = `No Rights Reserved.`——与 CC0
   语义互证（01-方案期审计按 OFL 记录，实际许可更宽松，均属可分发✓）。

结论：**随软件再分发与嵌入零义务**（CC0 无署名/随附文本强制要求，
许可全文仍随包存档）。

- 文件：`resources/fonts/Aileron-Regular.otf`、`Aileron-Bold.otf`
  （OTF/CFF，各 ~28KB；Bold 供粗体元素真字重渲染）
- 许可全文：`licenses/AILERON-LICENSE.txt`
- 来源：https://github.com/font-archive/Aileron（原发布 dotcolon.net）
- 接线：main.cpp addApplicationFont ×2 + Element.h TextStyle 默认
  fontFamily="Aileron"（仅拉丁字形，中文内容由 Qt 缺字回落系统字体，
  与原版行为一致）+ test_golden 黄金图同字体（锚定产品默认视觉路径）
- 注：思源黑体仍为界面（QSS）字体，两者职责不同、并存无冲突。
